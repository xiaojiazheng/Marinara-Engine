# 战斗难度与天气

这是继 #6302 战斗调度器之后，[#6305](https://github.com/Pasta-Devs/Marinara-Engine/issues/6305) 的实现记录，说明已商定范围和实现边界。

## 设置与难度

删除 **Battlefield Seed**(战场种子) 字段及摘要，保留 **Battlefield Size**(战场大小)。新遭遇获得内部随机种子，启动未来战斗时忽略旧战役种子偏好；保留已接受战斗种子、网格和重开行为。Classic 说明改为“Cinematic menu battles.”（电影式菜单战斗）

通过同一共享函数归一化难度，包括旧设置中的首字母大写形式。保留敌人伤害倍率 Casual 0.6、Normal 1、Hard 1.3、Brutal 1.6。Classic 和 Tactical 一样只缩放敌人伤害，并检查遭遇与战利品是否有同样大小写问题。遭遇创建时固定难度，不能因战斗中改设置而变化。

这些倍率仅属于 Traditional（当前旧引擎机制）。实现 5e、V20 或其他规则集时，必须按各自规则重新定义难度，不默认继承 Traditional 倍率。AI 决策调参与伤害缩放分开。

## 天气

使用现有战役天气和有场景依据的遭遇暴露程度。天气随遭遇保存；旧战斗存档缺字段时采用中性机制。未知暴露程度也中性，封闭环境视为遮蔽。天气别名归一到现有类型，设置类型时生成相符风力与能见度。

初始规则对双方相同：雨稍降火焰伤害、提高闪电伤害；强风惩罚明确标记的投射物攻击；低能见度惩罚明确依赖视线的攻击；雪提高 Tactical 步行成本。飞行与传送保留原移动语义。未标记能力不能凭名字推断投射物/视线属性。晴天/多云通常中性。预测、结算与 AI 估算使用共享函数，不消耗未来战斗掷骰。

两个战斗界面都显示已接受条件及效果。天气表现设置不能关闭机制。遭遇内天气固定；改天气能力、周期转变、随机雷击和炎热消耗暂缓。Summoning 和未来规则可复用天气契约，无须增加未完成的 UI 模式。

## 敌人决策

保留职责、性格、熟练度、合法性和资源核算。难度改变有界、带种子的决策波动：Casual 容许更多合理失误，Normal 接近当前基线，Hard 更稳定，Brutal 尽量减少失误但保留熟练度差异。同伴在所有难度都采用固定 Normal 基线，仍对真实天气和危险作出反应。Mindless 限制保持不变。

攻击、支援、站位和反应的评分考虑天气。Counterspell 和保护反应按威胁、成本及性格与跳过竞争。任何难度都不提供隐藏命令、未来骰子、免费资源或额外动作。GM 首领提示词包含已接受难度/天气及压迫与机会选择指导，引擎仍强制执行合法候选和预算。服务商失败时保留本地回退。

## 验证与交付

依次实现设置/正确性、天气、AI 接入。增加可运行回归，覆盖难度大小写、仅敌方伤害、天气暴露/别名/预测/移动、保存恢复、确定性敌人选择与同伴调参、反应费用和首领提示词边界。为过时种子偏好更新现有设置/地形测试用例。验证桌面/移动、两种主题和天气动画关闭情形。草稿转待审前运行基线、相关提示词与浏览器回归及本地 CodeRabbit。

调参数值只是初始游戏设计值，不是已验证的平衡。自动测试证明机制和不变量；真实服务商的首领质量及长期战役平衡需要实玩。延期 issue 在真正开始工作前保持未指派。

## 实现细节

共享条件位于 `packages/shared/src/features/combat-conditions.ts`。设置导入/创建以及遭遇、战利品、Classic、Tactical 消费端都会归一化难度。敌人决策波动按 Casual / Normal / Hard / Brutal 乘以 2.5 / 1 / 0.4 / 0.15，已保存熟练度与个性仍生效。Classic 估算采用与结算相同的对抗 d20 命中概率；Tactical 使用共享攻击预测。Tactical 普通档案按地形和天气成本评价追击路线；Mindless 改按合法空间步数最少选路。两种策略实际移动时都支付真实地形和天气成本。反应考虑预期威胁和资源稀缺，同样仅对敌人应用难度波动。

暴露于雨、大雨、风暴时，火焰伤害乘 0.85，闪电乘 1.15。明确的投射物在强风下损失 10 点命中精度，烈风下 15 点；明确依赖视线的攻击在能见度降低时损失 5 点、很差时 15 点。合并惩罚最多 25 点。Classic 每五点精度换为一点对抗攻击掷骰修正，并在条件面板显示该骰子惩罚。Tactical 暴露于雪/暴雪时，每进入一格额外花一点步行费用；飞行、传送不受影响。元素伤害物品也受雨修正，治疗和状态持续时间不受影响。

遭遇生成明确设置普通攻击及技能的 `projectile` / `requiresSight` 布尔值和 `battlefield.terrainBrief.exposure`。缺失攻击属性中性。明确暴露值优先；已识别封闭环境遮蔽，室外暴露，含糊环境未知。战役天气来自持久天气系统，缺失时采用已提交的场景天气。战斗开始消息标签会在界面模式更新前停止后台天气推进。条件保存在调度器与 Tactical 状态，矛盾/畸形导入被拒绝。旧存档无天气时保持中性；旧 Tactical 重开传入已接受条件（包括中性缺失），不重新采样变化后的战役天气。

设置导入仍校验旧字段以保证兼容与安全，但归一化导出移除它们。引擎保留明确的遭遇种子用于恢复、重开和回归复现；不会删除用途不同的 Experience 世界种子。

## 验证记录

本地基线 `pnpm check`（含本地化、类型、lint、生产构建）和 `pnpm version:check` 通过。Node 测试覆盖 295 个回归文件；并发构建短暂删除生成文件后，五项重跑成功。审查修复后重跑战斗回归，包括传入战斗标签、非战斗天气推进、加权追击、难度一致性、反应资源与首领上下文。

桌面浅色 Chromium 和移动深色 Chromium 验证设置/导入、两个战斗模式、关闭动画的天气、反应、重载、地形回退与恢复地图隔离。本地移动 WebKit 因缺少 libicu74、libjpeg-turbo8、libmanette-0.2-0、gstreamer1.0-libav 无法启动，仍列为 CI/人工验证。PR 记录最终审查结果与多次随机地图用例检查。
