# Game Mode：HUD 小组件

本指南介绍 Marinara Engine 的 Game Mode(游戏模式) 里的 HUD 小组件。HUD 是 heads-up display 的缩写，也就是贴在游戏画面左右两侧的小信息面板。下面会讲小组件的类型、开局前的检查步骤、面板的移动和锁定，以及小组件布局的分享方式。

## HUD 小组件是什么

HUD 小组件是游戏过程中用来记录各种数值的小面板，比如血条、金币数，或者某个同伴的信任度。每场游戏都能有自己的一套小组件。它们和 Roleplay 的 HUD 追踪器是两套东西。Roleplay 聊天里的那条追踪器信息条，见文末的相关指南。

小组件最多 4 个，左右两侧怎么分配随你。

只有为这场游戏开启了 **Custom HUD Widgets**(自定义 HUD 小组件) 选项，小组件才会生效。这个选项在设置向导里默认开启。开启之后，AI 游戏主持人（GM）会在生成世界的同时设计出一套初始小组件。

## 8 种小组件类型

小组件一共八种类型。GM 每创建一个小组件都会为它挑一种类型。自己手动搭建小组件时也可以自行选择。

| 小组件类型 | 显示内容 |
|---|---|
| **Progress Bar**(进度条) | 横向进度条，显示一个数值及其上限，比如生命值或体力。 |
| **Gauge**(仪表盘) | 半圆形仪表盘，显示一个数值及其上限。 |
| **Relationship Meter**(关系条) | 带里程碑刻度和文字标签的条，适合表现 NPC(玩家之外的角色) 的信任度或羁绊。 |
| **Counter**(计数器) | 一个大数字，比如金币、经过的天数或击杀数。 |
| **Stat Block**(属性块) | 一小格带名称的字段和数值，比如 STR 和 DEX，或者一个状态词。 |
| **List**(列表) | 一份简短的文字项目符号列表，比如当前目标。 |
| **Inventory Grid**(物品栏网格) | 物品格子组成的网格，可以带分类选项卡和物品数量。 |
| **Timer**(计时器) | 以分秒显示的倒计时，可以实时走秒。 |

## 会话开始前的检查窗口

只要存在自定义小组件，第一个回合之前就会插入一步开局检查。按下 **Start Game**(开始游戏) 的一瞬间，**Review Starting Widgets**(检查初始小组件) 窗口就会打开。它会列出全部初始小组件，让你在游戏把它们固定下来之前先做调整。

在这个窗口里可以：

- 对某个小组件按 **Edit**(编辑)，改它的初始数值，或者给 **Stat Block** 的字段改名。
- 按 **Remove**(移除)，去掉不想要的小组件。
- 按 **Back**(返回)，关掉窗口且不开始游戏。
- 按 **Start Game**，按当前显示的小组件开始游戏。

在已经进行中的游戏里开始新会话时，会出现一个类似的窗口。它的标题是 **Prepare Next Session Widgets**(准备下一场会话的小组件)，**Start Game** 的位置换成了 **Start Next Session**(开始下一场会话) 按钮，关闭按钮的文字也从 **Back** 变成了 **Cancel**(取消)。

## 游戏过程中修改小组件

游戏进行时，GM 会随剧情推进替你更新小组件的数值。GM 漏掉某次更新时，可以手动修正。

1. 在画面左边或右边找到那个小组件面板。
2. 点击小组件标题栏里的铅笔（**Edit**）按钮。
3. 在编辑窗口里改数值。比如给一根条设置新的 **Current value**(当前值) 和 **Maximum value**(最大值)。
4. 点击 **Save Changes**(保存更改)。

标题栏里还有一个小小的加号或减号。点击小组件标题栏就能折叠或展开它的主体部分。

## 移动和锁定面板

小组件面板默认锁定在原位。每个面板的标题栏里都有一个锁图标。

1. 点击锁图标解锁面板。面板会浮现一圈淡淡的轮廓，表示现在可以移动了。
2. 把面板拖到新位置。
3. 再次点击锁图标，把它重新锁定。

想把面板挪回默认位置，双击它的锁图标，或者在图标处于焦点状态时按 R 键。每个面板的位置和锁定状态都按游戏分别记住，布局不会在不同游戏之间通用。

在手机上，小组件显示成小胶囊而不是完整面板。点一下胶囊就能打开对应的小组件，点 X 关闭。

## 自己搭建小组件

小组件不一定要交给 GM 生成，也可以自己设计。手动小组件编辑器有两个入口：

- 在游戏设置向导里：开启 **Custom HUD Widgets**，再打开 **Build Widget Setup**(搭建小组件配置) 开关，编辑器就出现在开关下方。
- 在已有的游戏里：打开 **Chat Settings**(聊天设置)，再打开 **Widgets**(小组件) 部分。

在编辑器里从下拉菜单选一种小组件类型，然后按 **Add**(添加)。每个小组件可以设置：

- **Icon**(图标)：标题栏里显示的一个简短符号或 emoji。
- **Label**(标签)：小组件顶部显示的名称。
- **Type**(类型)：八种小组件类型之一。
- **Side**(所在侧)：**Left HUD** 或 **Right HUD**。
- **Accent**(强调色)：小组件的颜色。

这些之下，每种类型还有各自的字段。条用 **Value**(值) 和 **Max**(上限)，计数器用 **Count**(计数)，物品栏网格用 **Slots**(格子数) 和 **Contents**(内容)，计时器用 **Seconds**(秒数) 和 **Running**(是否运行)。编辑器会显示允许的 4 个名额里已经用掉几个。

在 **Chat Settings** 里，按 **Save Widgets**(保存小组件) 把改动应用到游戏，或者按 **Reset**(重置) 撤销尚未保存的修改。

## 用导入导出分享小组件

小组件布局可以存成文件，再加载到另一场游戏里。设置向导和 **Chat Settings** 的 **Widgets** 部分都有这两个按钮。

1. 按 **Export Widgets**(导出小组件)，把当前的小组件下载成一个 JSON 文件。JSON 是一种纯文本数据格式。
2. 在另一场游戏里按 **Import Widgets**(导入小组件) 并选中那个文件，就能加载同一套小组件。

在 **Chat Settings** 里导入之后，记得按 **Save Widgets**，加载进来的小组件才会真正生效。
