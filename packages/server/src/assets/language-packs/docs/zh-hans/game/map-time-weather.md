# Game Mode：地图、时间与天气

本指南介绍 Game Mode(游戏模式) 的地图面板，以及记录队伍周围世界变化的那几套系统：日期与时间、天气、队伍士气。地图有哪几种视图、怎么移动和缩放、怎么手动设定日期和时间，下面都会讲到。

## 地图面板

Game Mode 会在游戏画面上显示一个小地图面板，上面有当前地图名称、游戏天数，还有一个表示时段的天空图标。

在电脑上，地图是一块嵌在页面里的面板，一眼就能看清。在手机上，点左上角的地图图标，按钮标签是 **Open map**(打开地图)，点了会以弹出面板的形式打开地图。

面板可以拖动，也可以锁定位置。可拖动面板的具体用法见下方链接的 HUD 小组件指南。

## 网格视图与节点视图

地图有两种视图。用哪一种由 Marinara Engine 根据地图代表的场所类型自动决定，不需要手动切换。

- **grid**(网格) 视图用于开阔区域，比如大地图、地区或城市。它把地形画成一格格的彩色方块，包括草地、森林、水域、山地、沙漠、雪原、城镇、道路和洞穴。
- **node**(节点) 视图用于地下城、室内这类封闭区域。它把各个地点画成圆圈，用线连起来。还没发现的地点显示为一个问号图标。虚线代表还没走过的路径，实线代表已经走过的路径。

## 移动队伍

要移动，先在地图上选一个地点。可选的地点是有限制的：网格地图上，方块必须紧挨着队伍，而且已经发现过；节点地图上，节点必须与当前所在地点相连，或者已经发现过。点击其他方块和节点不会有任何反应。

1. 点击一个网格方块，或者在节点地图上点击一个节点。
2. 消息框上方会出现一个 **Destination:**(目的地) 标记，显示地点名称。
3. 输入消息并发送。Marinara 会在消息开头加上一小段文字，形如 `*moves to <place>*`。

要取消，点击 **Destination:** 标记上的清除按钮（那个 X）。

手机上的流程略有不同：先点一下节点选中它，再点底部的 **Set destination**(设为目的地)。标着 **You are here** 的节点就是当前所在位置。

## 缩放地图

每张地图的右上角都有缩放控件。

- 点 **Zoom in**(放大，加号按钮) 拉近。
- 点 **Zoom out**(缩小，减号按钮) 看得更全。

缩放范围是 75% 到 180%，每次调整 25%。

## 在多张地图之间切换

有些游戏不止一张地图或一个地区。地图多于一张时，地图面板顶部会出现一个小的下拉菜单，用它可以查看别的地图。队伍实际所在的那张地图会标上 **(Current)**。

## 生成新地图

地图面板左上角有一个魔杖按钮，标签是 **Generate another map**(另外生成一张地图)。点它就会用一张全新的地图替换当前地图。

如果游戏还没有地图，面板会显示 **No map yet**，旁边有一个 **Generate**(生成) 按钮，作用相同。

## 手动设定日期和时间

日期与时间控件在地图面板顶部，显示 **Day**(天数) 和一个数字，再加一个表示时段的小天空图标。

1. 点击 **Day** 控件。
2. 在框里输入新的天数，范围是 1 到 9999。
3. 从下拉菜单里选一个时段，可选项有 **Dawn**、**Morning**、**Afternoon**、**Evening**、**Night** 和 **Midnight**。
4. 点击别处或按 Enter 保存。

这属于手动覆盖，日期和时间由你自己定，与下面讲的自动时钟互不相干。时钟自己也可能显示 **Noon**，但 Noon 不在手动可选项里。

## 时间如何自动流逝

游戏时钟会自行走动。它靠固定的算式推进，不经过 AI，所以结果始终一致。每局新游戏都从第 1 天早上 08:00 开始。你的每一个行动都会把时钟往前推一段固定的时长。

| 行动 | 增加的时间 |
|---|---|
| 交谈 | 15 分钟 |
| 探索 | 30 分钟 |
| 一个战斗回合 | 5 分钟 |
| 一次短休息 | 1 小时 |
| 一次长休息 | 8 小时 |
| 赶路 | 2 小时 |

时钟越过午夜时，天数加一。

## 天气

天气同样由游戏自行记录，也是固定算式，不经过 AI。天气取决于生物群系和季节。生物群系指队伍所处的环境类型，比如沙漠、极地、海岸或山地。天气种类包括晴、多云、雨、暴风雨、雪、暴风雪、雾和沙暴。

行动之后天气可能变化。赶路和长休息之后变化最频繁，探索之后偶尔会变，其他情况下很少变。天气会影响游戏主持人（GM）描述每个场景时的气氛。

要在屏幕上看到天气效果，请在应用的外观设置里开启 **Dynamic weather effects (rain, snow, fog, etc.)**(动态天气效果) 这一项。它默认是开启的。开启后，雨、雪、雾等动画粒子会叠加显示在游戏画面上，并与当前天气和时段保持一致。更多显示选项见下方链接的外观设置指南。

## 队伍士气

游戏会在后台记录一个 0 到 100 的队伍士气分数，分为五个等级，从低到高依次是 Broken、Low、Steady、High、Inspired。

士气随剧情起伏。打赢一场战斗、完成一个任务、找到宝藏都会让它上升；打输、任务失败、失去同伴则会让它下降。时间一长，士气会慢慢回落到中间水平。

游戏里不会把士气显示成数字，它只在后台起作用：它会影响掷骰结果，Inspired 时加 2，Broken 时减 2；GM 描述队伍状态时的笔调也会随之改变。
