# 把世界书关联到角色和用户角色

这篇指南介绍如何把世界书关联到角色或用户角色，让它在对应的聊天里自动生效，同时也讲把世界书嵌入角色卡的做法，以及每个聊天各自的 **Lorebooks**(世界书) 控件。世界书就是一组由关键词触发的世界设定条目。第一次接触的话，先看[世界书总览](overview.md)。

## 挂载世界书的两种方式

把世界书挂到角色上有两种方式，效果完全不同，按需要选一种。

- **Link (Assign)**(关联/指派)：世界书留在你的库里，角色或用户角色只是指向它。只要聊天里有这个角色，或者用了这个用户角色，世界书就会自动生效。关联的世界书不会跟着导出的角色卡一起走。
- **Embed**(嵌入)：世界书被写进角色卡本身。导出或分享角色时，它会跟着卡一起走。嵌入只对角色可用，用户角色不行。

大多数情况下选关联就行。只有打算把世界书一起打包分享出去时，才需要嵌入。

## 编辑器里的 Lorebook 选项卡

角色编辑器和用户角色编辑器里都有 **Lorebook** 选项卡。

1. 打开一个角色或用户角色进行编辑。
2. 点击 **Lorebook** 选项卡。
3. 会看到一个 **Lorebooks** 区域，里面有两个按钮：**New**(新建) 和 **Assign Lorebook**(指派世界书)。

**New** 会新建一本世界书，并直接关联到当前编辑的角色或用户角色。它打开 **Create Lorebook**(创建世界书) 窗口，**Category**(分类) 已经设为 **Character**。

**Assign Lorebook** 用来关联库里已有的世界书。选择器里只列出 **Character** 分类的世界书。下一节详细说明。

## 指派一本已有的世界书

**Assign Lorebook** 选择器只显示 **Category** 为 **Character** 的世界书，编辑用户角色时也是这样。分类是 World 或 NPC 之类的世界书不会出现在选择器里，也不会出现在已指派列表里。想让它出现，就打开这本世界书，在 **Overview**(总览) 选项卡把 **Category** 改成 **Character**。用 **New** 按钮不会遇到这个问题，因为它建出来的就是 Character 分类。

1. 在 **Lorebook** 选项卡里点击 **Assign Lorebook**。
2. 在搜索框里输入世界书名称的一部分来找它。
3. 点击要用的世界书，旁边会出现一个对勾。
4. 在右侧选一个 **Scope**(生效范围)，见下一节。
5. 点击 **Assign**(指派)。

这本世界书就出现在已指派列表里了。每一行都有一个 **Scope** 按钮，随时可以改生效范围，还有一个垃圾桶图标用来解除关联。点击世界书名称可以在完整编辑器里打开它。

设为 Global 的世界书在每个聊天里都生效，因此不能再关联到角色或用户角色。Global 的说明见[世界书总览](overview.md)。

## Scope：哪些聊天可以用这本关联的世界书

**Scope** 决定关联的世界书允许在哪里生效。它不是指 Marinara 里的每一个聊天，而是指包含这个角色、或者用了这个用户角色的聊天。生效范围有三种。

- **All chats with [name]**(所有包含该角色的聊天)：默认值。只要聊天里有这个角色，或者用了这个用户角色，世界书就生效。
- **Disabled for all chats**(全部聊天中禁用)：关联保留，但世界书永远不生效。想暂时禁用又不想解除关联时用这个。
- **Specific chats**(指定聊天)：从一份清单里精确勾选聊天，只有勾上的聊天能用这本世界书。清单里列的是已经包含这个角色、或者用了这个用户角色的聊天。

选了 **Specific chats** 的话，至少要勾一个聊天才能保存。

以后想改生效范围，点击该行的 **Scope** 按钮，调整好再点一次 **Assign**。

## 把世界书嵌入角色卡

嵌入会把世界书写进角色卡，这样它就能随角色一起导出。这个功能只对角色有效。想分享一个自带世界设定的角色时就用它。

1. 在角色编辑器里打开这个角色。
2. 进入 **Lorebook** 选项卡。
3. 确认要用的世界书已经指派好（见上文）。
4. 在这本世界书所在的行上，点击 **Embed into card**(嵌入角色卡)。

这一行上会出现一个 **Embedded**(已嵌入) 角标。从此世界书条目就存在卡里，并随卡一起导出。

一张角色卡同时只能有一本嵌入的世界书。卡里已经有一本时，**Embed into card** 按钮会变灰，并给出提示“Remove the current embedded lorebook first”。要换一本，先把现有的嵌入副本移除。

嵌入之后又编辑了那本关联的世界书，就点击该行的 **Refresh**(刷新)。这会按世界书当前的条目重写嵌入副本，让卡里的内容保持最新。

## 管理已嵌入的世界书

角色卡里已经有嵌入的世界书时，已指派列表下方会多出一组控件，同时还会列出嵌入条目的只读清单。

- **Import Embedded Lorebook**(导入嵌入的世界书)：把卡里的条目变成库里一本正常的、可编辑的世界书，新建出来的世界书会反过来关联到这个角色。库里已经存在这样一份关联副本时，按钮文字变成 **Reimport Embedded Lorebook**(重新导入嵌入的世界书)。
- **Edit Embedded Lorebook**(编辑嵌入的世界书)：在完整编辑器里打开那本关联的世界书。在那里做的修改会自动同步回卡里的嵌入副本。
- **Remove from card**(从角色卡移除)：删掉卡里的嵌入副本，库里另外关联的世界书不受影响。

这一组功能对从别的工具导入的角色卡特别有用。导入的卡很多都自带嵌入的世界书，点一下 **Import Embedded Lorebook**，就能在 Marinara 里得到一份完全可编辑的版本。

## Chat Settings 里的 Lorebooks 区域

每个聊天都有自己的 **Lorebooks** 控件。在这里可以看到当前聊天里有哪些世界书生效，也可以只针对这个聊天做调整。

1. 打开一个聊天。
2. 打开 **Chat Settings**(聊天设置)。
3. 找到 **Lorebooks** 区域，计数角标显示有多少本世界书正在生效。

每一本生效的世界书都会带一个或多个角标，说明它为什么生效：

- **Chat**(聊天)：你手动把它固定到了这个聊天。
- **Global**(全局)：它是一本全局世界书。
- **Character**(角色)：它关联到了这个聊天里的某个角色。
- **Persona**(用户角色)：它关联到了这个聊天使用的用户角色。

生效内容可以只针对当前聊天调整。

- **Add Lorebook**(添加世界书)：把一本世界书固定到这个聊天，被固定的世界书会带 **Chat** 角标。
- 垃圾桶图标（**Remove from chat**，从聊天移除）：取消固定你手动添加的世界书。
- 闭眼图标（**Disable in this chat**，在此聊天中禁用）：只在这个聊天里临时隐藏自动生效的世界书，不解除关联。被禁用的世界书名称带删除线，并显示 **Disabled**(已禁用) 角标。
- 眼睛图标（**Enable in this chat**，在此聊天中启用）：让禁用的世界书在这个聊天里重新生效。

### Lorebook Token Budget

**Lorebook Token Budget**(世界书 Token 预算) 是这个区域里的一个数值输入框，用来限制这个聊天里最多能注入多少世界书文本，单位是 Token(模型切分文本的最小单位)。默认值是 **8192**，填 **0** 表示不限制。这个聊天级别的预算和每本世界书自己的 Token 预算是两回事，两个限制同时起作用。两者如何配合，见[世界书的 Token 预算与递归扫描](token-budgets.md)。
