# 自定义表情、贴纸和 GIF

本指南介绍能加进 Conversation(对话模式) 聊天的几类额外图片：自定义表情、自定义贴纸和搜索来的 GIF，同时说明怎么控制角色在回复里能用哪些自定义表情和贴纸。

这些功能只在 Conversation 模式里有。Roleplay 模式和 Game Mode 只有普通的表情选择器，没有自定义表情，没有贴纸，也没有 GIF 搜索。

## 这些功能在哪里

在 Conversation 模式的聊天里看消息输入栏，那里有一个圆形按钮，图标是一张笑脸，名字叫 **Emoji, GIFs & stickers**(表情、GIF 和贴纸)。点击它，输入栏上方会打开一个小面板。

面板里有这几个选项卡：

- **Emoji**：标准表情网格，外加一个星形选项卡 **Custom emojis**(自定义表情)，放你上传的图片。
- **GIFs**：实时 GIF 搜索。
- **Stickers**(贴纸)：你上传的贴纸。

开启了其他输入工具时，还会多出一个 **Tools**(工具) 选项卡。手机上这些选项卡会在键盘上方以抽出式面板的形式打开。

## 自定义表情

自定义表情是一张小图，上传一次就能在任何 Conversation 聊天里反复用。在消息里写成短代码，也就是用冒号把表情名字包起来，比如 `:kekw:`。

自定义表情在整个档案范围内共享。上传一次，处处可用。

### 上传自定义表情

1. 打开 **Emoji, GIFs & stickers** 面板，切到 **Emoji** 选项卡。
2. 点击星形选项卡 **Custom emojis**。
3. 点击 **Upload**(上传)，选择一个或多个图片文件。
4. 在 **Name this emoji**(给这个表情起名) 窗口里输入名字，点击 **Add**(添加)。

新表情会出现在 **Custom emojis** 网格里。

表情名字有严格规则。长度为 1 到 32 个字符，只能用小写字母、数字和下划线。输入了空格或大写字母也没关系，应用会自动清理：字母转成小写，其他字符转成下划线。

自定义表情图片不能超过 256 x 256 像素，上传时应用会检查。名字在你所有自定义表情里必须唯一，取了已被占用的名字就会看到这样的报错：`An emoji named ":name:" already exists.`

动图 GIF 文件也能当自定义表情上传，在聊天里会正常播放动画。这和下面讲的 **GIFs** 选项卡是两回事。

### 使用自定义表情

点击 **Custom emojis** 网格里的任意一格，就会把它的短代码放进消息。这个操作不发送消息，只插入文字。也可以手动输入短代码，比如 `:kekw:`。名字要用小写，和保存时完全一致。

### 重命名、删除、导出和导入

点击 **Custom emojis** 选项卡顶部的 **Edit**(编辑) 进入编辑模式。

编辑模式下：

- 点击某一格打开 **Rename emoji** 窗口，改完点击 **Rename**(重命名)。
- 点击某一格上的小垃圾桶标记可以删除这个表情。**Delete emoji**(删除表情) 窗口会提示：已经用过它的消息会改为显示纯文字。
- 点击 **Export**(导出)，把所有自定义表情下载成一个名为 `marinara-custom-emojis.json` 的文件。图片就存在这个文件里，所以可以直接带走。
- 点击 **Import**(导入) 载入之前导出的文件。名字或尺寸不合规、以及和已有名字冲突的表情会被跳过。

## 自定义贴纸

自定义贴纸和自定义表情差不多，只是用于更大的图片。贴纸写成 `sticker:name:`，显示时永远是独占一行的大图。

在同一个面板里打开 **Stickers** 选项卡。上传、命名、重命名、删除、导出和导入的做法都和表情一样，区别有这些：

- 上传窗口的标题是 **Name this sticker**(给这个贴纸起名)。
- 贴纸图片不能超过 512 x 512 像素。
- 贴纸名字在你所有贴纸里唯一，重名会提示 `A sticker named "sticker:name:" already exists.`
- 导出下载的文件名是 `marinara-custom-stickers.json`。

### 发送贴纸

点击网格里的某个贴纸，会弹出 **Send sticker** 窗口问你想怎么用，有两个选择：

- **Send & reply**(发送并回复)：立刻把贴纸作为一条单独的消息发出去，让角色接着回应。
- **Add to message**(加入消息)：把 `sticker:name:` 这段文字放进消息，你可以继续往下打字。

## GIF 搜索（Giphy）

**GIFs** 选项卡搜的是 Giphy，一个大型在线 GIF 库。在搜索框里打字就能找 GIF，也可以直接翻热门列表。点击一张 GIF 就发进聊天。

### GIF 搜索需要密钥

GIF 搜索需要一个免费的 Giphy API 密钥。API 密钥是一串类似密码的秘密字符，Marinara Engine 拿它代表你去和 Giphy 服务通信。没有密钥时，**GIFs** 选项卡显示的是一张设置引导卡，而不是搜索结果。

设置 GIF 搜索的步骤：

1. 打开 Giphy 开发者控制台：`https://developers.giphy.com/dashboard/`。
2. 为网页应用创建一个免费的 API 密钥。
3. 把密钥写进 `.env` 文件，这是 Marinara 的服务器设置文件。

在 `.env` 里加上这样一行：

```
GIPHY_API_KEY=your_key_here
```

加好密钥后重启 Marinara。`.env` 文件的完整说明见下方链接的服务器配置指南。

### GIF 内容分级

GIF 结果使用 Giphy 的成人内容分级。这一项是写死的，在应用里改不了。结果里可能出现暗示性或成人向的 GIF，搜索时请留意。目前没有离线或纯安全的 GIF 来源。

## 把图库图片标记为表情或贴纸

已经存进 Character Gallery(角色图库) 或 Persona Gallery(用户角色图库) 的图片，都可以标记为自定义表情或贴纸。被标记的图库图片只属于那一个角色或用户角色，也只在有他们参与的聊天里生效。

标记图库图片的步骤：

1. 打开 **Character Editor**(角色编辑器) 或 **Persona Editor**(用户角色编辑器)。
2. 切到 **Gallery**(图库) 选项卡，打开 **Images**(图片) 子选项卡。
3. 把鼠标移到图片上，点击左上角的小标记按钮。
4. 选择 **Make emoji**(设为表情) 或 **Make sticker**(设为贴纸)。
5. 在 **Custom Emoji** 或 **Custom Sticker** 窗口里输入名字。

标记按钮会变成显示刚才起的名字。

尺寸限制在这里同样有效。**Make emoji** 上限是 256 x 256 像素，**Make sticker** 上限是 512 x 512 像素。图片对所选类型来说太大时，会弹出一条红色错误提示。

想改已标记的图片，再点一次它的标记按钮。菜单里有 **Rename**、类似 **Switch to sticker**(改为贴纸) 的切换项，以及类似 **Remove emoji**(取消表情) 的移除项。标记不会移动或复制图片，它仍然是一张普通的图库图片。

## 候选偏好设置

Marinara 可以告诉正在回复的角色，你的哪些自定义表情和贴纸能用在这次回复里。这由 **Selection preferences**(候选偏好设置) 控制。

点击齿轮图标 **Selection preferences** 打开面板。这个图标在 **Custom emojis** 选项卡和 **Stickers** 选项卡的顶部都有，打开的是同一项设置。设置按聊天分别保存，所以每个聊天可以不一样。

面板里有一行模式选择，共三个选项：

- **Semantic**(语义，默认)：挑出最贴合近期聊天内容的表情和贴纸供角色选用。语义模式用的是本地嵌入模型，也就是一个跑在你自己机器上的小型 AI 模型。它不可用时，这个模式会退回随机。
- **Random**(随机)：每次回复给出一组随机候选。
- **Tool-call**(工具调用)：每次回复由一次模型调用挑出合适的项。你需要在随之出现的下拉菜单里选一个连接。连接没设或调用失败时，会退回语义模式。群聊中一回合有多个角色回复时，这一回合会跳过 Tool-call，改用语义模式挑选。

模式下面是 **Max offered (each)**(每类最多候选数)，也就是每回合提供给角色的自定义表情名和贴纸名各有多少个。默认是 20，可以设为 1 到 100。

## 自定义表情和贴纸的显示效果

在 Conversation 聊天里，`:kekw:` 这样的表情短代码会在文字行内显示成一张小图。如果一条消息里除了表情短代码没有别的内容，它们会放大显示。

`sticker:wave:` 这样的贴纸永远显示为独占一行的大图。

找不到对应名字时，比如表情已经被删掉了，消息里就会显示纯短代码文字，例如 `:kekw:`。

## 回应只能用全局表情池

你可以用自定义表情回应一条消息。回应只能用主自定义表情，也就是全局池里的表情。图库标记的表情、贴纸和 GIF 都不能用作回应。消息回应的用法在 Conversation 模式的入门指南里讲。
