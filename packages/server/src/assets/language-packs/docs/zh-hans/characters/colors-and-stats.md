# 角色颜色与 RPG 属性

本指南介绍 Marinara Engine 的 **Colors**(颜色) 选项卡和 **Stats**(属性) 选项卡。这两个选项卡在角色编辑器和用户角色编辑器里都有。Colors 决定角色或用户角色在聊天里的外观，Stats 用来设置生命值、饥饿度这类可追踪的数值。

## Colors 选项卡

每个角色和用户角色的编辑器里都有一个 **Colors** 选项卡，可以设置三种颜色：名字颜色、对话颜色、消息框颜色。哪个输入框留空，对应部分就沿用应用主题的默认颜色。

打开 Colors 选项卡的步骤：

1. 在角色编辑器里打开一个角色，或者在用户角色编辑器里打开一个用户角色。
2. 在选项卡列表中点击 **Colors** 选项卡。
3. 这时应该能看到一张实时的 **Preview**(预览) 卡片，下面是三个颜色输入框。

**Preview** 卡片里有一个示例名字和一个示例消息气泡。改动任意一种颜色，卡片会立刻跟着变，保存之前就能看到效果。

### Extract Colors from Avatar

**Extract Colors from Avatar**(从头像提取颜色) 按钮会根据头像图片自动挑出名字颜色、对话颜色和消息框颜色。只有存在头像时按钮才可用。上传头像之前，按钮是禁用状态，显示为 **Upload an avatar first**。提取完成后，这三种颜色仍然可以手动改。

### 三种颜色

用颜色输入框选取，或者直接输入数值：

- **Name Display Color**(名字显示颜色)：名字的颜色。这个输入框还支持 CSS 渐变，也就是几种颜色之间的平滑过渡。示例值：`linear-gradient(90deg, #f59e0b, #ef4444)`。
- **Dialogue Highlight Color**(对话高亮颜色)：对话引号内文字的颜色。示例值：`#ffd700`。
- **Message Box Color**(消息框颜色)：聊天消息气泡的背景色。用半透明颜色效果最好。示例值：`rgba(0, 0, 0, 0.5)`。

半透明颜色会让背景从气泡里透出来一部分。`rgba` 格式依次是红、绿、蓝和一个 alpha 值，alpha 从 0(完全透明) 到 1(完全不透明)。

## 这些颜色分别用在哪里

每种颜色影响聊天界面的不同部分：

- 名字颜色用于聊天消息里的显示名。角色的名字颜色还会用在侧边栏选项卡上，用户角色的名字颜色还会用在用户角色选择器里。
- 对话颜色用于对话引号内的文字，英文直引号和其他样式的引号都能识别。这段文字还可以在 **Settings**(设置) 里设为加粗。Conversation(对话模式) 聊天不使用它。
- 消息框颜色决定该角色或用户角色在 Roleplay(角色扮演) 聊天里的消息气泡背景。Conversation 和 Game(游戏模式) 聊天不使用它。

## Stats 选项卡

每个角色和用户角色同样都有一个 **Stats** 选项卡。属性就是 HP(生命值)、STR(力量)、饥饿度条这类数值。开启属性后，应用会把当前数值写进提示词（Marinara Engine 发给 AI 的那段文字），让 AI 知道当前状态。这里设置的数值是新聊天的起始默认值，开始游玩后可以交给智能体修改，见下文关于智能体的小节。

角色的 **Stats** 选项卡和用户角色的 **Stats** 选项卡布局不同，下面分开介绍。

### 角色属性：Enable RPG Stats

角色只有一个开关：**Enable RPG Stats**(启用 RPG 属性)。关闭时，下面的内容既不显示也不发送。开启后会出现两个区块：

- **Pools**(资源条)：带名字的条，包含当前值、最大值和颜色。新角色默认带一条 HP 和一条 MP，都是 100/100。点击 **Add**(添加) 新增一条，点击某一行的 X 删除它。
- **Attributes**(属性值)：带名字的数值。新角色默认带 STR、DEX、CON、INT、WIS、CHA，全部为 10。点击 **Add** 新增一项，点击某一行的 X 删除它。

### 用户角色属性：两个区块

用户角色的 **Stats** 选项卡分成两个独立区块，各有各的开关。

第一个区块是 **Persona Status Bars**(用户角色状态条)，用 **Enable Persona Stats**(启用用户角色属性) 打开。这些条用来追踪生理和心理需求。开启后默认带 Satiety、Energy、Hygiene、Mood 四条，都是 100/100。列表在 **Status Bars** 下面管理，每条有名字、当前值、最大值和颜色。点击 **Add** 新增一条，点击 X 删除一条。

第二个区块是 **RPG Attributes**(RPG 属性值)，用 **Enable RPG Attributes**(启用 RPG 属性值) 打开，机制和角色卡一样，给用户角色提供 **Pools**(默认 HP 和 MP，都是 100/100) 和 **Attributes**(默认 STR、DEX、CON、INT、WIS、CHA，全部为 10)。

### 规则集角色表

安装规则集（如 5e (SRD 5.1)）后，两个 **Stats** 页签都会出现 **Ruleset sheets**（规则集角色表），每个规则集有一个可展开条目。如果角色卡仍保存着已卸载规则集的表，该区域也会显示。

1. 展开条目，点击 **Add a sheet**，载入默认值。
2. 编辑属性、分区字段、攻击或法术列表、技能和豁免的训练及额外加值。布局由规则集决定。熟练加值、被动察觉等计算值会随编辑更新，不能直接修改。
3. 照常保存角色或 Persona。

这些是初始配置。新游戏会复制角色表；游戏内修改不影响角色卡。**Add from catalog** 打开可搜索的法术、攻击和能力目录。添加的行是可编辑副本。

随等级或属性变化的数字是只读的，带有 "Set by the ruleset" 说明，并在编辑时重新计算。目录有更新文本时，**Review** 并排显示已保存内容与新内容。**Update selected** 仅更新勾选行的文本；数字、开关、其他列和未勾选行保持不变。

规则集缺失时，角色表仍会保存并随角色卡导出，但不会发给 AI。重新安装后可以继续编辑，也可用 **Remove** 删除。每张表上限为 64 KB。来自较新版本、当前无法读取的表也会保留；只提供 **Remove this sheet**，避免新表意外覆盖它。

角色表不受 **Enable RPG Stats** 和 **Enable RPG Attributes** 控制。Marinara Engine 自身规则忽略它们；使用规则集的游戏则用它们代替普通属性进行检定。

## 智能体如何更新属性

**Stats** 选项卡上的数值只是起始默认值。想让属性在聊天过程中变化，就要开启对应的智能体。智能体是在聊天过程中同时运行的 AI 帮手。

- **Character Tracker** 智能体根据战斗、治疗和剧情事件调整角色的 RPG 属性以及用户角色的 **RPG Attributes**。
- **Persona Stats** 智能体在每条消息之后，根据故事里发生的事情调整 **Persona Status Bars**。

不开启对应的智能体，数值就一直停在设定好的默认值上。**Stats** 选项卡本身不会自动更新任何东西。开启方法见可下载智能体参考。

## 属性在 HUD 里怎么显示

属性开启后，会在聊天过程中显示在 HUD 小组件里。HUD 是抬头显示的缩写，也就是实时展示当前数值的一个小面板。各种条以颜色渐变呈现，一眼就能看清。完整的显示方式以及移动、隐藏的方法，见 HUD 指南。
